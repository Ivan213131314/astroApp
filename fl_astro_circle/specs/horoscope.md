# Модуль: Horoscope

**Responsibility:** Отображение астрологических прогнозов по знакам зодиака.
**Spec file:** `specs/horoscope.md`

## Обзор
Модуль позволяет пользователю выбрать знак зодиака и прочитать прогноз на сегодня, завтра или неделю.

## Экраны
1.  **Список Знаков** (`/horoscope`):
    *   Сетка (GridView) из 12 знаков зодиака.
    *   Каждый элемент: иконка (`assets/home/image-*.png`) и название.
    *   При клике: переход к деталям (`/horoscopeDetail`).

2.  **Детали Гороскопа** (`/horoscopeDetail`):
    *   Получает `signIndex` через аргументы маршрута.
    *   Показывает текст прогноза.

## Логика и Данные
Реализация: `HoroscopeService` (`lib/services/horoscope_service.dart`).
Модель данных: `HoroscopeData`.

*   **Источник данных:** Firestore, коллекция `horoscopes`.
*   **Периоды:** `today`, `tomorrow`, `this_week`.
*   **Ключ документа:** `${zodiacSign}_${date}_${period}`.
*   **Локализация:** Названия знаков переводятся (`horoscope_list.*`).

## Особенности
*   Прогноз кэшируется (стандартный кэш Firestore).
*   Есть возможность подписки на обновления через Stream.

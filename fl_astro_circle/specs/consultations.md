# Модуль: Consultations (Astrologers)

**Responsibility:** Каталог астрологов и интерфейс для связи с ними (чат, аудио, видео).
**Spec file:** `specs/consultations.md`

## Обзор
Модуль предоставляет список доступных экспертов для консультации и навигацию к каналам связи.

## Экраны
1.  **Список Астрологов** (`/astrologers`):
    *   Показывает список экспертов с фото, рейтингом, специализацией, языками и ценой.
    *   Кнопки быстрого доступа: Call, Chat, Video Call.
2.  **Детали Астролога** (`/astrologersDetail`):
    *   Подробная информация о специалисте.
3.  **Каналы Связи:**
    *   `/chat` (AstrologerChatScreen)
    *   `/call`
    *   `/videocall`

## Данные
**Важно:** В текущей реализации (`lib/pages/astrologers/astrologers.dart`) список астрологов **захардкожен** (mock data) внутри виджета `_AstrologersScreenState`. Данные не загружаются с сервера динамически.
Пример данных:
*   Name: "Brooklyn Simmons"
*   Type: "Vasthu consultation, Vedic Astrology"
*   Charge: "$30/hour"

## Ограничения
*   Реальная интеграция с WebRTC или чат-платформой пока не видна в проанализированном коде UI (только переходы на экраны-заглушки или макеты).

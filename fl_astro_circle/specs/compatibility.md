# Модуль: Compatibility

**Responsibility:** Проверка астрологической совместимости между двумя знаками.
**Spec file:** `specs/compatibility.md`

## Обзор
Модуль позволяет пользователю выбрать два знака зодиака (свой и партнера) для проверки их совместимости.

## Экраны
1.  **Выбор Знаков** (`/compatibility`):
    *   Два вертикальных скроллера (PageView) для выбора знака слева и справа.
    *   Кнопка "GO" по центру.
    *   На фоне используется `assets/compatibility/bgImage.png`.

2.  **Ввод Даты** (`/compatibilityBirthDate`):
    *   Принимает выбранные знаки (названия и картинки) как аргументы.
    *   Пользователь уточняет даты рождения для более точного расчета (предполагается).

3.  **Детали** (`/compatibilityDetail`):
    *   Отображение результата совместимости.

## Логика
В текущей реализации экрана выбора (`CompatibilityScreen`) логика выбора знаков реализована через синхронизацию индексов `PageView` (`leftSelectedIndex`, `rightSelectedIndex`).
Данные для расчета (знаки) передаются на следующий экран через аргументы навигации.

# Модуль: Natal Chart

**Responsibility:** Построение натальной карты и AI-интерпретация положений планет.
**Spec file:** `specs/natal_chart.md`

## Обзор
Модуль строит натальную карту пользователя (по дате, времени и месту рождения) и предоставляет психологический анализ основных положений (Солнце, Луна, Асцендент).

## Логика AI (NatalChartAiService)
**Файл:** `lib/pages/natalChart/natal_chart_ai_service.dart`

Использует OpenRouter API для генерации текстовых интерпретаций.

### Категории Анализа (`NatalChartCategory`)
1.  **Sun Sign:** Личность, эго, жизненная цель.
2.  **Moon Sign:** Эмоции, подсознание, внутренний мир.
3.  **Rising Sign (Ascendant):** Социальная маска, первое впечатление.

### Типы Генерации
1.  **Тизер (`generateTeaser`):**
    *   Одно провокационное предложение в стиле таблоида ("Yellow-press / teaser headline energy").
    *   Цель: создать интригу и указать на скрытое противоречие.
    *   Генерируется параллельно для всех трех знаков (`generateAllTeasers`).

2.  **Детальный Анализ (`generateDetail`):**
    *   Генерируется для выбранной категории.
    *   Контент: 4 параграфа (Основной паттерн, Скрытое противоречие, 3 примера из жизни, 2 совета на неделю).
    *   Стиль: Психологически точный, жесткий, без "воды" и мистики.

## Данные
Для работы сервису требуются уже вычисленные знаки:
*   `sunSign`, `moonSign`, `risingSign`.
Сервис *не* вычисляет их сам, а принимает как входные параметры. Вычисление позиций планет происходит в другом месте (предположительно в контроллере экрана или отдельном калькуляторе).
